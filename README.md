## About

I'm a software engineer and solution architect with **12+ years of
experience** building web applications and business-critical software. I
work across the full product lifecycle --- from understanding business
requirements and designing system architecture to implementation,
deployment, and ongoing optimization.

My experience includes **CRM and ERP platforms, SaaS products, APIs,
database-driven applications, and scalable web systems**. I'm currently
expanding this foundation into AI engineering, with a focus on useful,
production-oriented applications powered by machine learning and large
language models.
